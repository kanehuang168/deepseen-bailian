# DeepSeen 百炼

把经验炼成技能，让技能百炼成钢。使用用户的语言，默认简体中文；使用宿主实际可用且获准的工具。

用户使用英文或要求英文时，读取 [English instructions](SKILL.en.md)。

## 选择路线

明确要求找现成技能就搜；要求整合现有方法就拼；要求把自己的经验做成技能就炼。用户已选择或意图清楚时直接执行；不明且影响结果时，问用户选择搜、拼、炼或组合，再继续。

- **搜**：查已有技能和可用网络，读取候选正文，按 CREATE 检查任务、资料、标准、步骤、样例和兜底。记录来源、许可、适配点和缺口；不能访问或未试用就标未知。需要评估外部方法时，若宿主允许且吸星已安装，应交接候选正文、来源和目标并使用实际返回结果；不可用则按来源一致性、可迁移性与目标差异自行分析并标明，勿冒称调用成功。未获授权不安装或运行外部代码。
- **拼**：比较候选与用户经验的范围、依赖、冲突和许可，用自己的表达形成候选；仅有一个来源而无可组合经验时，继续寻找或说明缺口。用相同任务试跑。
- **炼**：读取现有材料，分批问少量关键问题；先澄清对象和术语，追问判断依据与正反例，区分未问、未明确和明确否定，以及加分、必要和排除条件。信息足够时生成真实 SKILL.md、使用说明和必要参考并试跑；核心判断缺失时交付草稿并继续追问，不编造事实。

按阶段使用[成品骨架](references/skill-template.md)、[自检清单](references/quality-checklist.md)、[正反例](references/examples.md)和[搜炼流程示例](references/workflow-examples.md)。模板与示例均需按任务适配；模拟不冒称真实验收。

## CREATE：从经验到工作方法

逐项覆盖：C 定任务与适用边界；R 备资料与每次输入；E 立判断标准；A 排步骤和检查；T 给输出样例及正反例；E 设缺资料、拿不准及禁止事项的兜底。记录用户确认、案例观察、推断和未知；不强制所有任务评分或编造权重。

## 工作流体检与试炼

划清需要理解的工作、确定性程序、运行系统和人工决策；以实际接线为准，未实现标待建设。检查描述与实际运行、重复或过时规则、授权、失败恢复与模型升级后的复验；副作用状态不明时先查原任务，不盲目重复提交。

使用同一输入比较旧版或无技能与候选，覆盖正常、缺资料、反例和未参与编写的新案例。合成、静态、真实运行及独立评审分别标注；没对照不能声称质量提升。交付来源、候选、使用说明、验证与剩余限制；不要公开用户私人材料。仅生成不等于授权发布或发送。
