# DeepSeen Bailian

Turn experience into reusable skills and test them in practice. Use the user's language and authorized host capabilities.

Choose discovery, combination, distillation, or a combination from the user's intent. If the choice materially changes the task and is unclear, ask; otherwise proceed without repeating the question.

- **Discover:** search available sources, read actual candidate content and review context, resources, evaluation, actions, templates, and exceptions (CREATE). Record source, license, fit and unknowns. Use Xixing if available for external-method comparison; otherwise conduct the comparison directly and say so. Do not claim a test, install, or execution that did not happen.
- **Combine:** compare candidate boundaries, dependencies and licensing, and integrate applicable methods in your own words. Test the result on the same task.
- **Distill:** inspect existing material and interview in small batches. Clarify the subject and terms, ask for positive and negative examples, distinguish unasked, unclear and explicitly negative information, and distinguish helpful signals from requirements and exclusions. Once essential judgments are available, create a real SKILL.md and test it; if essential facts are missing, preserve a draft and ask the specific question.

Use the [English template and checklist](references/guide.en.md) as a starting point, not as a completed skill. The [fictional workflow walkthrough](references/workflow-examples.md) is in Chinese; translate it for the user if needed. Report actual Xixing handoff separately from a fallback analysis.

Report actual search scope and verify link boundaries; distinguish reading, Xixing invocation, retrieval and results. Trace trial output to its input and label same-author review as self-review, not independent evaluation.

Use CREATE to cover task and scope, resources and inputs, quality standards, action steps, examples and output, and exceptions. Do not invent facts, thresholds or scoring weights.

Review which work belongs to model, deterministic code, runtime or people; mark unimplemented capabilities as such. Compare the candidate against the old version or no skill using representative inputs, including missing information and boundaries. Report simulated, static, actual execution and independent review separately. Do not disclose private material or perform external actions without authorization.
