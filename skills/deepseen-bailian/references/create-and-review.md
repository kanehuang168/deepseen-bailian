# CREATE 与试炼参考

CREATE 是按需收集问题的框架，不是必须逐格填写的表单。

| 环节 | 关键问题 |
| --- | --- |
| C 定任务 | 谁在什么情况下使用？希望得到什么？什么时候不适用？ |
| R 备资料 | 需要哪些背景、文件、每次输入及来源？ |
| E 立标准 | 什么算做好？哪些判断必须有用户确认或证据？ |
| A 排步骤 | 先后顺序、分支、检查和人工决定在哪里？ |
| T 给样例 | 交付什么？正例、反例和容易混淆的例子是什么？ |
| E 设兜底 | 缺资料、拿不准或工具不可用时怎么办？禁止做什么？ |

评分、权重和阈值只在任务需要且有依据时使用。没有资料时写待确认；模糊的建议值不能当成事实。引用用户已经说过的内容，不把 AI 推断冒充用户决策。

检查任务的实际动作与权限，梳理模型、程序、运行系统和人的职责。受理状态不明先查询原任务；未接入的能力标待建设。对照旧版或无 Skill 的同一输入，记录正常、缺资料、反例和未参与编写的案例。结构检查、合成试跑、真实任务、独立评审和生产效果分开报告。
