# Skill 成品骨架

按任务适配，不机械填空。名称使用小写英文、数字、连字符；description 说明何时使用及不适用的范围。将下面字段替换为本任务确认的信息；未知写“待确认”，不得将此模板作为完成品交付。

```markdown
---
name: skill-name
description: 说明完成的任务、适用条件和不适用情况。
---

# 技能名称

## 目标与适用范围
说清用户要得到什么，何时使用；列出不应触发的情况。

## 输入和资料
列出每次必需信息、可选资料、已知来源；缺失时先使用已有信息。

## 判断标准
写明有依据的判断因素、作用条件和边界；区分事实、用户陈述、推断和未知。无证据的阈值或权重不填。

## 执行步骤
按实际依赖列出读取、判断、执行和检查；每个关键分支说明触发条件、动作、产物与修订去向。

## 输出
写明交付格式、必要字段、来源与未确定事项。

## 示例
提供已授权或虚构并标明的输入和可检查输出；包含正常及边界情况。

## 异常与边界
缺资料时如何补问或继续；工具不可用、受理状态不明及权限不足时如何处理；列出不能做的事。
```

方法、实例或模板过长时放 references 并在主文件中明确如何按需读取；脚本和外部服务仅按实际需要提供和验证。按 @references/quality-checklist.md 核查，示例参见 @references/examples.md。
