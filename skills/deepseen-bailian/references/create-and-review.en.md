# CREATE and workflow review

CREATE guides adaptive questions; it is not a mandatory form.

| Part | Key questions |
| --- | --- |
| Context | Who uses it, when, for what result, and when is it inapplicable? |
| Resources | What background, files, recurring inputs and sources are needed? |
| Evaluation | What counts as good, and which judgments require user confirmation or evidence? |
| Actions | What is the order, branching, checking and human decision? |
| Templates | What is delivered, and what positive, negative and confusing examples matter? |
| Exceptions | What happens when information or tools are missing, or judgment is uncertain? What is forbidden? |

Use scores, weights and thresholds only when needed and supported. Mark absent information unconfirmed; a vague suggestion is not a fact. Reuse what the user already said and never present AI inference as their decision.

Review actual actions, permissions and the responsibilities of model, code, runtime and people. Query the original task when acceptance is uncertain; mark unconnected capabilities as pending. Compare the same inputs against the old version or no skill. Cover normal, missing-information, negative and new cases; separately report static checks, synthetic runs, real tasks, independent review and production effects.
