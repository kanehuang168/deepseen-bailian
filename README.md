# DeepSeen 百炼

作者：祥子｜跨境无疆&DeepSeen AI创始人  
产品品牌：DeepSeen

**把经验炼成技能，让技能百炼成钢。** 百炼帮助你找现成 Skill、整合方法，或通过问答把自己的经验变成可执行的 Skill，并用案例验证。

## 安装与使用

```sh
npx skills add kanehuang168/deepseen-bailian
```

查看入口：`npx skills add kanehuang168/deepseen-bailian --list`。技能正文见 [SKILL.md](skills/deepseen-bailian/SKILL.md)。例如：“帮我找一个会议纪要 Skill，并评估是否适合我”或“把我的客户判断经验炼成 Skill，先采访我”。
